# DMS

Dokumentenmanagement mit Texterkennung, automatischer Sortierung, intelligenter Suche und Fragen an die eigenen Dokumente. Ein Produkt von Strainovic IT, Steinach, Schweiz.

- Upload von PDF, PNG und JPG mit Duplikaterkennung
- Texterkennung lokal für digitale PDFs, sonst per Mistral OCR
- Dokumenttyp, Felder und Schlagwörter werden automatisch erkannt
- Suche nach Stichwörtern und nach Bedeutung
- Chat mit Quellenangaben über alle Dokumente

Architektur, Pipeline und Befehle sind in [`CLAUDE.md`](./CLAUDE.md) beschrieben, der Einstieg für Beitragende in [`CONTRIBUTING.md`](./CONTRIBUTING.md).
